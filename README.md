## Nguyen Huyen Trang

Software Engineer and AI Researcher based in Da Nang, Vietnam.

**1.5 years** building production backend systems · **2 years** of applied ML research · **2 peer-reviewed papers** (ACM, Springer) · **Champion**, Danang AI4Life AI Challenge 2025

I work at the point where machine learning has to survive production: systems that are evaluated before they are trusted, observable when they fail, and cheap enough to run.

---

### Experience

**Software Engineer, Enosta** · Jun 2025 – present\
Taxi-booking platform with 20K registered users. Owned booking, destination selection and coupon features end to end. Moved background jobs to AWS SQS workers with batching and retries, and propagated trace IDs from API to queue with SigNoz to debug asynchronous failures. History-based destination suggestions are chosen by about 47% of users.

**AI Researcher, Semantic Adaptive Query Optimization (VKU, funded by SRA Japan)** · 2025 – 2026\
SQL representation learning for cardinality estimation in PostgreSQL: a multi-sense Word2Vec model with context attention, sense gating and knowledge distillation from CodeBERT, trained on 520K SkyServer queries, served inside a C extension for PostgreSQL.

### Publications

- **IDE: A Differential Evolution-Based Algorithm for Summarizing Multiple Vietnamese Comments.** First author. ICIT 2025, Springer, pp. 63–72. [doi:10.1007/978-3-032-13102-7_6](https://doi.org/10.1007/978-3-032-13102-7_6)
